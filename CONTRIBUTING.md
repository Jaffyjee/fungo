# Contributing to FUNGO

Thank you for considering a contribution. Useful contributions include documentation corrections, accessibility improvements, translation, brand asset refinements, issue reports, and thoughtful community proposals.

## Before you start
1. Read README.md, COMMUNITY.md, and the risk notices.
2. Search existing issues and pull requests to avoid duplicates.
3. For substantial changes, open an issue describing the problem and proposed solution.
4. Never include private keys, seed phrases, credentials, personal data, or unpublished security-sensitive details.

## Pull request guidelines
- Keep changes focused and explain why they are needed.
- Use clear, descriptive commit messages.
- Link related issues.
- Include screenshots for material visual changes.
- Verify links and spelling before submission.
- Do not add unsupported claims about token supply, audits, partnerships, listings, utility, rewards, or performance.

## Documentation standards
- Distinguish confirmed facts from proposals and TBD fields.
- Date material statements and provide primary evidence where possible.
- Link on-chain claims to the relevant explorer transaction or account.
- Never describe the project as audited unless a public, in-scope report exists.
- Do not publish a token address until independently verified.

Contributions are reviewed at maintainers' discretion. Contributing does not imply employment, compensation, token allocation, or other entitlement.
