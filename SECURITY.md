# Security Policy

## Scope
Report vulnerabilities affecting this repository, project-controlled websites, official accounts, or project software. This repository currently serves as project documentation; do not assume a token contract or production application exists.

## Reporting
Open a private security advisory through GitHub's **Security** tab where available. If unavailable, contact maintainers through a verified GitHub account. Do not post exploitable details publicly before maintainers have had a reasonable opportunity to investigate.

Include:
- A concise description and impact.
- Reproduction steps or proof of concept.
- Affected component, version, or commit.
- Suggested mitigation, if known.

Do not include real user secrets, seed phrases, private keys, or other people's personal data.

## Response expectations
Maintainers will assess reports in good faith, but no response or remediation timeframe is guaranteed. Do not exploit a vulnerability beyond what is necessary to demonstrate it, access other users' data, or disrupt services.

## Wallet safety
The project will never need your seed phrase or private key. Anyone asking for these is attempting theft. Do not trust links sent by unsolicited DMs.
