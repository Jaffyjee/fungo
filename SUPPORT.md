# Support

This repository is the documentation home for FUNGO ($FUNGO).

## Where to ask for help

- **Documentation errors:** Open a GitHub issue and include the affected file, relevant section, and a clear description.
- **Feature or documentation proposals:** Use the repository's feature-request issue template.
- **Security concerns:** Follow [SECURITY.md](SECURITY.md). Do not publish exploit details, private keys, seed phrases, or credentials in a public issue.
- **Token or transaction questions:** Include public transaction signatures or public explorer links only. Never share wallet recovery phrases or private keys.

## Before requesting support

1. Check the [README](README.md), [FAQ](FAQ.md), and [Technical Overview](TECHNICAL_OVERVIEW.md).
2. Verify token information independently. Maintainer-provided details are labelled where independent verification is pending.
3. Include enough non-sensitive detail to reproduce a documentation issue.

## Important limitations

This repository does not provide individualized investment, legal, tax, or financial advice. No response guarantees token value, liquidity, returns, listings, rewards, or transaction outcomes.
